### 🎩 Introduction

**GU Cafeteria** is a modern, highly responsive web application designed exclusively to streamline the food ordering process for university students and staff. Built with a focus on speed and usability, it offers a lag-free browsing and checkout experience to save valuable time between classes.

## ✨ Key Features

| Feature | Description |
| :--- | :--- |
| **📱 Fully Responsive** | Optimized layouts for mobile, tablet, and desktop screens. |
| **⚡ Real-Time Menu** | Browse the latest cafeteria offerings with updated pricing. |
| **🛒 Smart Cart** | Easily add items, manage quantities, and review your order. |
| **🔍 Search Engine** | Quickly find your favorite dishes with instant search. |
| **🚀 Fast Performance** | Lightning-fast rendering powered by Vite and React. |

## 🛠️ The Tech Stack

- **Frontend Framework:** `React.js`
- **Build Tool:** `Vite`
- **Language:** `JavaScript` / `TypeScript`
- **Styling:** `Tailwind CSS`
- **Typography & Icons:** `Google Fonts (Poppins)`, `Lucide React`, `FontAwesome`
